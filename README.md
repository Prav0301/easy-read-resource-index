# CAMHS Accessible Information Directory

## About this project

This repository began as a structured index of UK Easy Read health resources and has evolved into a clinically curated directory of accessible information resources relevant to:

- Child and Adolescent Mental Health Services (CAMHS)
- Neurodevelopmental services
- Learning disability services
- Mental health inpatient settings
- Medication and psychopharmacology discussions
- Mental Health Act and rights-based information
- NHS navigation and hospital preparation
- Accessible psychoeducation for children, young people, families, and carers

The repository remains hosted under the original `easy-read-resource-index` name for continuity, but the wider project now functions as a broader accessible-information infrastructure layer for CAMHS and neurodevelopmental practice.

---

# Why this project exists

Accessible health information is often:

- fragmented across NHS trusts and charities
- difficult to discover
- inconsistently indexed
- variably maintained
- inconsistently adapted for neurodevelopmental or learning disability populations
- heavily adult-oriented even when clinically useful for adolescents

Clinicians frequently spend significant time searching for:

- Easy Read medication leaflets
- Mental Health Act explanations
- autism-appropriate explanations
- hospital preparation resources
- crisis information
- communication aids
- visual guides
- rights-based information
- CAMHS explanations for families and young people

This repository aims to reduce that fragmentation by creating:

- a clinically curated resource index
- a searchable static portal
- a metadata-rich repository
- a governance-aware ingestion workflow
- a reusable framework for future curation and review

# Clinical philosophy

The project intentionally prioritises:

- practical clinical usability
- neurodevelopmental accessibility
- communication support
- shared decision-making
- psychopharmacology accessibility
- rights-based communication
- low-cognitive-load navigation
- transparency about limitations and suitability

The repository is not intended to function as:

- clinical guidance
- prescribing advice
- legal advice
- official NHS policy
- a substitute for clinical judgement

Instead, it functions as:

- a curated discovery layer
- a communication support tool
- a structured signposting system
- a practical clinical resource directory

---

# What counts as an “accessible resource” here

The repository intentionally includes more than strict Easy Read documents.

Included resource types may include:

- Easy Read leaflets
- Accessible PDFs
- Visual guides
- Symbol-supported information
- Plain-English youth-facing information
- VERA medication resources
- Hospital preparation guides
- Communication aids
- Accessible rights information
- Video resources
- Audio resources
- Neurodevelopmentally adapted psychoeducation

This reflects real-world clinical practice, where many highly useful resources are:

- accessible but not technically Easy Read
- youth-friendly but not learning-disability-specific
- adult-oriented yet clinically adaptable for adolescents
- visually simplified without formal Easy Read structure

# Verification and governance

Resources are preferentially sourced from:

- NHS organisations
- government websites
- recognised UK charities
- established learning disability organisations
- academic collaborations
- professional collaborations

Examples include:

- NHS England
- NHS Wales
- Great Ormond Street Hospital
- South London and Maudsley NHS Foundation Trust
- CNWL SPECTROM
- Macmillan Cancer Support
- Mencap
- National Autistic Society

The project attempts to:

- avoid dead links
- avoid duplicate entries
- prioritise publicly accessible resources
- distinguish restricted-access resources
- preserve source attribution
- maintain review transparency

However:

- resource quality varies
- some resources age quickly
- links may become unavailable
- accessibility standards differ across organisations
- suitability for children and adolescents may require clinician interpretation

Clinical review remains essential before use.

# Clinical safety and limitations

Important limitations:

- Age relevance tags are heuristic and clinically interpreted.
- Some resources use adult imagery but remain useful for older adolescents.
- Some resources are parent-facing rather than young-person-facing.
- Some resources are plain English rather than formal Easy Read.
- Resources should not be treated as official local policy.
- Medication information does not replace prescribing discussion.
- Mental Health Act information may become outdated as legislation changes.

Always:

- verify currency
- verify local policy compatibility
- assess developmental suitability
- consider literacy, neurodevelopmental profile, and communication needs
- apply clinical judgement before sharing

# Contributing

Contributions should prioritise:

- reputable UK sources
- clinically useful resources
- accessible formatting
- neurodevelopmental suitability
- copyright awareness
- non-duplicative indexing
- open-access resources where possible

Please avoid:

- uploading copyrighted material without permission
- indexing dead or generic homepage links
- adding unverified resources without metadata
- conflating plain-English resources with formal Easy Read without annotation
