# Easy Read Resource Index

A curated working index for Easy Read resources relevant to UK health, social care, neurodevelopmental, learning disability, safeguarding, SEND, NHS access, and CAMHS contexts.

## Purpose

This repository is intended to help collect, organise, and review Easy Read resources from reputable UK sources. It is designed as a practical resource index rather than a clinical guideline.

## Repository structure

- `DOWNLOADS/` — local holding folders for downloaded or archived Easy Read resources, organised by topic.
- `SOURCES_REGISTER.csv` — register of organisations, repositories, and source pages to review or monitor.

## Notes

Resources should be checked for source credibility, publication date, accessibility, relevance to UK services, and suitability for the intended audience before use.
