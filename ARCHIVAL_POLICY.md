# Archival Policy

## Purpose

This document defines how resources should be evaluated for local archival within the CAMHS Accessible Information Directory.

The repository primarily functions as:

- a curated index
- a metadata and discovery layer
- a clinical signposting system

Selective archival is used to improve:

- reliability
- offline access
- inpatient usability
- resilience against dead links
- printable clinical workflows

The repository is not intended to become a full mirror of external websites.

---

# Core principles

## Prefer indexing before archiving

Resources should initially be:

- indexed
- classified
- quality reviewed
- metadata enriched

before any local download is considered.

---

## Selective archival only

Local archival should prioritise:

- NHS-produced resources
- government-produced resources
- openly accessible PDFs
- clinically high-value resources
- stable documents likely to remain useful long term
- resources frequently reused in CAMHS/inpatient/LD settings

Avoid mass downloading.

---

# Priority categories for local storage

High-priority archival categories include:

- Mental Health Act rights leaflets
- inpatient admission resources
- psychotropic medication leaflets
- STOMP/STAMP resources
- autism and learning disability communication tools
- hospital preparation guides
- crisis planning resources
- visual communication aids
- NHS navigation guides

---

# Archive decision framework

Codex or reviewers should evaluate:

| Question | Consideration |
|---|---|
| Is the source reputable? | NHS, government, established charity |
| Is the resource open access? | No login/paywall required |
| Is the URL stable? | Direct PDF or stable landing page |
| Is it clinically useful? | High CAMHS/LD/neurodevelopmental utility |
| Is it likely to be reused frequently? | Ward packs, psychoeducation, MHA discussions |
| Is the resource difficult to rediscover? | Poor indexing elsewhere |
| Would offline access improve care? | Inpatient/crisis contexts |
| Is local storage legally acceptable? | Copyright and attribution reviewed |

---

# Resources that should generally NOT be archived

Avoid downloading or mirroring:

- login-restricted resources
- subscription-only content
- copyrighted libraries without permission
- dynamic interactive platforms
- duplicate versions of the same document
- temporary campaign pages
- resources with unclear ownership

---

# Local storage conventions

Archived resources should be stored inside:

- `DOWNLOADS/`

using topic-based folders.

Example:

`DOWNLOADS/Medication/lithium_easy_read.pdf`

---

# Naming conventions

Use:

- lowercase
- underscores
- concise descriptive filenames

Avoid:

- spaces
- generic filenames like `leaflet.pdf`
- duplicated version labels unless clinically relevant

---

# Metadata expectations

Archived resources should ideally include:

- Local_Copy
- Local_Path
- Archive_Status
- Copyright_Status
- Verification_Status
- Last_Verified

---

# Copyright principles

The repository should:

- preserve attribution
- retain source references
- avoid removing source branding
- avoid implying ownership
- avoid redistribution where prohibited

When uncertain:

- link externally instead of archiving locally.

---

# Review cadence

Suggested review frequency:

| Resource type | Review frequency |
|---|---|
| Medication resources | 6–12 months |
| Mental Health Act resources | 6 months |
| Crisis pathways | 3–6 months |
| Hospital preparation guides | 12 months |
| General psychoeducation | 12–24 months |

---

# Clinical safety

Local archival does not imply:

- endorsement
- policy approval
- prescribing guidance
- legal accuracy

Clinical judgement and local governance remain essential.
